# Troubleshooting — DC Replication

## 증상

DC 간 복제 상태를 점검하는 과정에서 다음 오류를 확인했습니다.

```text
8524 (DNS lookup failure)
```

이 오류는 복제 과정에 필요한 DNS 이름 해석이 실패했음을 의미합니다. 오류 메시지만으로 특정 DNS 설정이나 레코드를 근본 원인으로 확정할 수는 없습니다.

## 진단

복제 상태를 확인하기 위해 다음 명령을 사용했습니다.

```powershell
repadmin /replsummary
repadmin /showrepl
```

복제 실패 상태 및 DNS 조회 관련 오류를 `repadmin` 출력에서 확인했습니다. 당시 오류가 위 두 명령 중 어느 출력에 나타났는지는 별도로 특정하지 않습니다.

## 점검 및 재수행

DNS 관련 설정을 점검한 뒤 복제를 재수행했습니다. 재수행 과정에서 다음 메시지를 확인했습니다.

```text
SyncAll terminated with no errors.
```

실행한 복제 재수행 명령의 전체 옵션은 기록으로 확인되지 않아 기재하지 않았습니다.

## 재검증

복제 재수행 후 `repadmin /replsummary`를 다시 실행해 **복제 실패 건수 0**을 확인했습니다.

| 단계 | 확인한 결과 |
| --- | --- |
| 오류 발생 | `8524 (DNS lookup failure)` |
| 복제 재수행 | `SyncAll terminated with no errors.` |
| 최종 점검 | `repadmin /replsummary` 실패 건수 0 |

## 확인 범위

**확인한 사실**

- DNS 조회 관련 복제 오류 발생
- `repadmin` 명령을 이용한 복제 상태 점검
- DNS 관련 설정 점검 및 복제 재수행
- 복제 작업의 오류 없는 종료 메시지와 최종 실패 건수 0 확인

**확정하지 않은 사항**

- 오류를 유발한 특정 DNS 설정 또는 레코드
- 개별 설정 변경과 복제 정상화 사이의 직접적인 인과관계
- 복제 재수행 시 사용한 전체 명령과 옵션

이번 사례에서 가장 중요하게 확인한 것은 장애 원인을 추측만으로 단정하지 않고, 조치 후 다시 명령을 실행해 복제 상태를 검증하는 과정이었습니다.
